# Airlines-Flightys-Analysis-Projects
✈️ Airlines Flight Data Analysis Project
Overview

This project explores and analyzes a large dataset of 300,000+ domestic flight records to uncover patterns in airline operations, ticket pricing, travel timing, and route distribution. The goal is to perform end-to-end exploratory data analysis (EDA), clean the dataset, and generate meaningful visual insights that help understand how flight characteristics influence ticket prices and travel trends.

The analysis focuses on airlines operating between major Indian cities and examines factors such as departure/arrival time, number of stops, airline frequency, and price variations.

Dataset

The dataset contains detailed flight information, including:

Airline name

Source and destination cities

Departure and arrival time

Duration of flights

Number of stops

Ticket class and price

It includes over 300K records representing domestic air travel across major Indian hubs like Delhi, Mumbai, Bangalore, Kolkata, Hyderabad, and Chennai.

Tools & Technologies

Python

Pandas – data cleaning and manipulation

NumPy – numerical operations

Matplotlib – data visualization

Jupyter Notebook – analysis environment

Project Workflow

Data Loading

Imported raw CSV dataset into Python using Pandas

Checked structure, size, and sample records

Data Cleaning

Removed unnecessary index columns

Inspected missing or unusual values

Validated duration and pricing extremes

Exploratory Data Analysis

Airline frequency distribution

Source vs destination city comparisons

Stop distribution analysis

Departure and arrival time patterns

Minimum and maximum ticket price analysis

Visualization

Bar charts for airline and city frequency

Pie charts for time distribution

Scatter plots for price vs timing

Comparative visual insights

Key Insights

Vistara and Air India operate the highest number of flights in the dataset

Most flights are single-stop journeys

Ticket prices vary significantly based on departure and arrival time

Major metro cities dominate both origin and destination traffic

Late-night and peak-hour flights show noticeable price differences

Results

The project demonstrates how structured EDA can reveal pricing patterns and operational trends in airline travel. The visualizations highlight time-based price variations and route concentration across major cities, offering insights useful for travel analytics and business decision-making.
